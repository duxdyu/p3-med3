# P3 MED · 维护版

本文档由AI生成，可能有些地方不清楚，欢迎大家一起完善。项目也是借助AI完成的，如果有熟悉Pascal和Delphi 13的大佬，非常欢迎一起维护！

本项目是大航海家3（Patrician III）中文版的游戏内辅助工具，原作者是大佬wei，已经通过QQ与大佬沟通，大佬已同意开源按照MIT协议开源。

游戏内可以通过 **F2** 打开信息与编辑界面，查看城市、事务所、船只、物产、地中海贸易点等数据，并修改部分游戏数据。

本项目在原 MED 源码基础上继续维护，采用 **Delphi 13 / Win32 / VCL** 构建。产品是 `P3MED.exe` 和 `MED3.dll`，**运行不需要 Python、PowerShell、C/C++ 编译器或其他辅助脚本**。

## 安装和使用

将同一版本的两个文件放在一起，建议使用游戏目录内的 `P3Med3`：

```text
Patrician III/
  Patrician3.exe（或原版 P3.exe）
  P3Med3/
    P3MED.exe
    MED3.dll
    MED.ini       # 个人配置；不存在时由工具按需生成
```

1. 启动游戏并读取存档。
2. 运行 `P3Med3/P3MED.exe`。默认匹配窗口标题 `大 航 海 家 3`，不是EXE文件名；标题不同可在启动器输入框中填写实际标题。
3. 挂钩成功后启动器隐藏，按 **F2** 打开／关闭 MED。
4. 退出游戏后，启动器自动退出。

启动器负责连接已运行的游戏，**不会替你启动游戏EXE**。也可以先开启动器，再启动游戏。

更新时只替换两个产品文件，保留自己的 `MED.ini` 和游戏存档。详细步骤、卸载及排错见 [INSTALL.md](INSTALL.md)。

## 支持范围

- 对应已核对的**中文版 x86 内存布局**，当前开发环境为现代版2.1。
- P3Modern不是基本挂钩功能的必需依赖；代码在存在P3Modern时使用其窗口协作逻辑。
- 不支持直接套用到任意语言版、任意重定位EXE或未知内存布局。
- 历史基线有XP SP3和Win10验证记录；本轮新增功能及地中海修复的运行验证为 **Win10窗口模式**。不能把历史记录当作最新版全部模式的验收。
- 自然冻港开始时间尚未充分核实：当前读取已冻结状态与解冻事件，不凭冬季日期编造提前冻结预警。
- 丰收／歉收天气是独立事件，**不是**小麦、蜂蜜等商品的固定冬季产量修正。

## 从源码构建

使用 **Delphi 13（RAD Studio 37.0），Win32**。没有需要安装到IDE中的第三方组件，也不依赖PI或P3Modern的源码。

1. 从有权使用的本机Delphi SDK准备XP兼容的 `Winapi.UIAutomation.pas` 副本，见 [dependencies/README.md](dependencies/README.md)。可以手动准备，**不强制使用Python**。
2. 在Delphi 13打开根目录 **`MED.groupproj`**。
3. 确认目标为 **Win32**，选择 **Build All**；不要用F9运行DLL工程。
4. IDE原始产品输出到 **`build/compiled/p3-med3/`**：`MED3.dll`、`P3MED.exe`。手动部署时另复制`runtime/MED.ini`；已有个人配置应保留。

使用`python -B scripts/build.py app --bds "Delphi安装目录"`可自动编译并组装完整的 **`build/p3-med3/`**，包含上述两个产品和随仓库提供的`MED.ini`。输出目录不含编译辅助文件，无需从现有发布包补文件。详见[构建说明](BUILDING.md)与[配置来源](runtime/README.md)。

编译工作由Delphi完成，包括Pascal中的内联x86汇编；没有C/C++构建链、代码转换器、从旧DLL提取代码或构建后补丁步骤。SDK准备与可选自动化脚本不参与游戏运行。

完整构建说明（包括无需Python的步骤）见 [BUILDING.md](BUILDING.md)。

### 可选自动化

已安装Python 3.11及自动化所需模块时，可使用已有维护脚本：

```powershell
$env:BDS = 'C:\Program Files (x86)\Embarcadero\Studio\37.0'
python scripts/prepare_dependencies.py
python scripts/build.py all
```

这会使用同一套Delphi工程并运行离线检查，不是另一种编译器。普通使用者不需要运行这些脚本。

## 目录

| 路径 | 内容 |
|---|---|
| `MED.groupproj` | 产品组：MED DLL＋启动器 |
| `tests/Tests.groupproj` | 离线测试组 |
| `tests/med/` | 测试工程、测试单元及配套资源 |
| `src/med/` | 产品Delphi源码、工程、窗体及资源 |
| `src/shared/` | 随仓库提供的物产规则源码 |
| `src/sdk-overlay/` | 从本机SDK生成的兼容副本，Git忽略，不公开分发 |
| `dependencies/` | SDK准备与依赖说明 |
| `docs/` | 功能、验证范围与发布方法 |
| `scripts/` | 仅SDK准备、可选构建/IDE驱动、白名单源码导出 |
| `build/` | 编译输出与缓存，Git忽略 |

Delphi 13 不强制目录布局；本项目采用 `src/` 放产品源码、`tests/` 放测试、`build/` 放生成产物。窗体 `.pas/.dfm` 和工程资源保留相邻，便于 IDE 管理。目录约定和 Git 文件范围见 [目录说明](docs/PROJECT-STRUCTURE.md)。当前目录可直接作为 Git 仓库，也可按 [发布方法](docs/PUBLISHING.md) 导出干净源码包。
