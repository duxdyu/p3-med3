# 常用信息：事件、战争及数值显示

## 城市事件

同城同类合并为一个图标。有当前实例时显示正常图标＋右下数量，不叠沙漏；
全部确定未发生时显示半透明图标＋右下沙漏。数量表示该类未完成记录总数，
可以包含当前与未来实例，不等于燃烧建筑数；单击详情查看实际组成。

右键仅使用“删除事件”“删除未来事件”，当前与未来并存时两项可同时出现。
删除不弹确认框，失败提示保留。各类型的范围如下：

| 操作 | 范围 |
| --- | --- |
| 火灾、瘟疫“删除事件” | 删除本城该类当前及未来记录；瘟疫不额外调用死亡处理 |
| 冻港“删除事件” | 解除冻结并处理本城全部恢复记录，保留原生天气内部量 |
| 收成“删除事件” | 结束本城当前收成效果及通知收尾 |
| “删除未来事件” | 仅取消本城同类已确认未发生的预约，保留当前事件 |

操作前核对记录身份和集合，操作后核验效果、回收与非目标事件；
无法确认的阶段不会强行当作未来。未知火势提示“火势暂未确定，请推进少量游戏时间等待刷新”。
清除不恢复已经损失的人口、建筑和货物。

瘟疫通过逐实例观察确认启动，不只使用全城共享疾病位。
收成阶段1至3处于效果期，阶段3的调度时间才是计划结束时间；阶段4、5属于通知收尾。
封锁、抵制和港口攻击不在MED状态列表展示，也不提供删除功能。

## 战争

状态列显示围城盾牌，战争列显示“当前局势[距下一阶段的天数]”：

| 显示 | 意义 |
| --- | --- |
| `来袭[约5]` | 按当前条件预计约5次每日检查耗尽生成计数，可能延期，不是已排定开战 |
| `围城[5]` | 已围城、敌军进军，距正式交战约5天（向上取整） |
| `交战[未知]` | 正在交战，没有固定结束时间 |
| `掠夺[3]` | 已被攻破，距解除围城约3天 |
| `解除`、`胜利`、`失败` | 已结束的短暂结果提示；之后主格恢复空白 |

不足一天显示`<1`；无法确定时间写`未知`。方括号从不表示已持续天数。
战前沿用原有90天内提示范围。条件性预估不伪装成有沙漏的确定未来事件。

有围城图标时，点击图标或战争格查看攻击方、下一阶段、开始时间和可核实结果。
没有围城图标时点击战争格不弹详情。
攻击方分为统治者军队与原生强盗/雇佣兵类；“强盗、雇佣兵、野蛮部落”是原生同类
在不同界面的称呼，不是三个独立枚举。

围城解除不自动意味着获胜；胜负须来自匹配城市、日期和本次持续时间的原生结果消息。
信息不足就不猜结果。对象还在收尾，不代表还在围城。
战争图标只提供详情，不支持强制清除或强制胜利。

## 为什么部分数值为空

以下保留MED原来的阈值提示规则，列宽调整没有改变阈值：

| 列 | 显示条件 |
| --- | --- |
| 满意度 | ≤10 |
| 房屋 | 三类住房占用指标最大值＞90% |
| 水井 | 当前供给指标＜80% |
| 道路 | 当前完成比例＜80% |

未触发提示时留空；人口/道路计算分母为0也会留空。旧数值读取路径未全面区分读取失败，
因此不能把空白等同于100%或保证一切正常。

最终列宽：房屋、水井、道路各48像素，状态120，战争70。状态图标过多时显示`+N`，
点击查看溢出详情；无战争数据时单元格为空，不填横线或空括号。
