# 常用信息：事件、战争及数值显示

## 城市事件

已排定未开始事件用半透明图标＋沙漏，当前效果用正常图标，单击看详情。
合并火灾的数字表示**事件实例数量**，不等于燃烧建筑数。

右键“清除当前火势（N个实例）”统一结束这一组已经发生的火势，保留同城未来火灾、
冻港等其它事件。它停止后续传播，并完成原生燃烧建筑收尾；不恢复人口、建筑和货物损失。
未来火灾仍单独取消。处于启动/收尾歧义状态的实例显示`?`，先推进少量时间并刷新，
不要把无法确认状态的记录强制混入批量清除。

## 战争

状态列显示围城盾牌，战争列显示“当前局势[距下一阶段的天数]”：

| 显示 | 意义 |
| --- | --- |
| `来袭[约5]` | 按当前条件预计约5次每日检查耗尽生成计数，可能延期，不是已排定开战 |
| `围城[5]` | 已围城、敌军进军，距正式交战约5天（向上取整） |
| `交战[未知]` | 正在交战，没有固定结束时间 |
| `掠夺[3]` | 已被攻破，距解除围城约3天 |
| `解除`、`胜利`、`失败` | 已结束的短暂结果提示；之后主格恢复空白 |

不足一天显示`<1`；无法确定时间写`未知`。方括号从不表示已持续天数。
战前沿用原有90天内提示范围，较远估计保留在详情。条件性预估不伪装成有沙漏的确定未来事件。

点击图标或战争格查看攻击方、下一阶段、开始时间和可核实结果。
攻击方分为统治者军队与原生强盗/雇佣兵类；“强盗、雇佣兵、野蛮部落”是原生同类
在不同界面的称呼，不是三个独立枚举。

围城解除不自动意味着获胜；胜负须来自匹配城市、日期和本次持续时间的原生结果消息。
信息不足就不猜结果。对象还在收尾，不代表还在围城。
战争图标只提供详情，不支持强制清除或强制胜利。

## 为什么部分数值为空

以下保留MED原来的阈值提示规则，列宽调整没有改变阈值：

| 列 | 显示条件 |
| --- | --- |
| 满意度 | ≤10 |
| 房屋 | 三类住房占用指标最大值＞90% |
| 水井 | 当前供给指标＜80% |
| 道路 | 当前完成比例＜80% |

未触发提示时留空；人口/道路计算分母为0也会留空。旧数值读取路径未全面区分读取失败，
因此不能把空白等同于100%或保证一切正常。

最终列宽：房屋、水井、道路各48像素，状态120，战争70。状态图标过多时显示`+N`，
点击查看溢出详情；无战争数据时单元格为空，不填横线或空括号。
